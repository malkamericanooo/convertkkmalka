Sebelum memakai: alat ini khusus petugas kesehatan dan kader yang berwenang. Kami (pengembang) tidak menyimpan, tidak melihat, dan tidak memakai data warga: PDF hanya diproses sesaat untuk dikonversi, hasilnya langsung dikirim ke browser Anda, lalu dibuang. Penanggung jawab data adalah instansi kesehatan yang mengunggahnya. Hasil otomatis bisa keliru, wajib diperiksa. Baca ketentuan & kebijakan data
Bisa pilih lebih dari satu. Kalau cuma satu kategori, hasilnya satu file.
Ini format kedua: satu file per kategori (tanpa versi gabungan), kolomnya persis template impor. Alamat diisi RT, jenis kelamin dibaca dari NIK, orang tua dari KK yang sama. Tempat lahir, nomor HP, dan posyandu tidak ada di PDF sehingga dikosongkan (posyandu diisi otomatis kalau PDF menyebutnya). Sel kuning = perlu dicek petugas.

File yang sudah dikonversi:
Format: Baris hijau = Kepala Keluarga, baris putih = anggota keluarga. Umur dihitung dari TANGGAL LAHIR (dd-mm-yyyy) pada tanggal acuan. Anggota ≥ 18 tahun dihitung ke kolom "Jumlah Anggota Keluarga". File kategori umur berisi 2 sheet: "Jumlah per KK" (jumlah KK di paling atas, lalu jumlah anggota per kategori) dan "Daftar Nama" (siapa KK-nya dan siapa anggotanya di tiap kategori, dibedakan warna).
